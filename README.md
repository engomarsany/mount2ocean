## 🛠️ Tech Stack & Key Architectural Highlights
- **Frontend Architecture**: Native HTML5, Modular CSS3 Design Tokens, Vanilla JavaScript ES6+.
- **Data Synchronization**: Synchronous `localStorage` Engine with Cross-Tab `storage` & `CustomEvent` Event Listeners.
- **GitHub Pages Deployment**: Auto-deployed on `main` branch with UTF-8 clean encoding & cache-busting versioning tags (`?v=v21...`).
- **Responsive Design**: Mobile-first glassmorphism UI, high-contrast glowing neon typography & dynamic animations.
